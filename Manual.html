Caret Finder

Double-tap Shift to circle the text cursor, like "Find My Mouse" but for where you're typing.

1. What it does

When you double-tap either Shift key, Caret Finder draws a bright ring around the text cursor (the "caret") in the document you're typing in.

  • The ring starts large and shrinks onto the cursor. Movement is easier to catch with side vision.
  • It stays on screen until you press any key, then fades away. That key still types normally.
  • If no text cursor can be found, you hear the Windows "Exclamation" sound.
  • The ring never takes focus and never blocks typing or clicking. You can keep typing while it's showing.

It has been tested with WordPad, Firefox and VS Code. It's also designed to work with LibreOffice Writer and most other Windows programs.

2. How to download

Caret Finder is a single file called CaretFinder.ahk. Get it from the project page on GitHub:

https://github.com/bthorton/cursor_finder

Option A: download everything as a ZIP (easiest)

  1. Open the project page linked above.
  2. Click the green Code button, then Download ZIP.
  3. Open your Downloads folder, right-click the ZIP file, and choose Extract All….
  4. Move the extracted folder somewhere permanent, for example your Documents folder. Don't leave it in Downloads if you plan to start it automatically.

Option B: download just the script

  1. On the project page, click CaretFinder.ahk.
  2. Click the Download raw file button (a downward arrow, near the top right of the file).
  3. Move the file to a permanent folder, for example Documents.

If Windows marks the file as downloaded from the internet: right-click CaretFinder.ahk, choose Properties, and if there's an Unblock tick box at the bottom, tick it and click OK.

3. How to install (and what you need first)

What you need

  • Windows 10 or Windows 11.
  • AutoHotkey version 2. This free program runs .ahk scripts. Version 1 won't work; the script will tell you if the wrong version tries to run it.
  • Sound turned on, if you want to hear when no cursor can be found.
  • No administrator rights. Neither AutoHotkey (installed the ways below) nor Caret Finder needs them.

Step 1: install AutoHotkey v2

Choose one of these:

From the AutoHotkey website (recommended)
  1. Go to https://www.autohotkey.com and click Download, then choose v2.0.
  2. Run the installer. If it offers a choice, install for the Current user only, which doesn't need administrator rights.
With winget (Windows' built-in package manager)

Open a terminal (press Windows, type Terminal, press Enter) and run:

winget install --id AutoHotkey.AutoHotkey --exact

This downloads the official installer from the AutoHotkey Foundation.

Without installing anything (portable ZIP)
  1. On the AutoHotkey website, download the .zip version of v2 instead of the installer.
  2. Extract it into a folder of your own.
  3. To run Caret Finder, right-click CaretFinder.ahk, choose Open with, then Choose another app, and pick AutoHotkey64.exe from that folder.

AutoHotkey isn't officially available in the Microsoft Store. Avoid look-alike apps there.

Step 2: start Caret Finder

  1. Double-click CaretFinder.ahk.
  2. No window opens. That's normal. A small green square with a white H appears in the system tray, at the bottom right of the screen by the clock. If you can't see it, click the small up-arrow (^) next to the clock.

Step 3 (optional): start it automatically when you sign in

  1. Right-click CaretFinder.ahk and choose Create shortcut.
  2. Press Windows+R, type shell:startup and press Enter. Your personal Startup folder opens.
  3. Move the new shortcut into that folder.
  4. Recommended: right-click the shortcut, choose Properties, and set Target to name AutoHotkey itself, followed by the script in quotes. For example: 
    "C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" "C:\Users\YourName\Documents\Cursor_Finder\CaretFinder.ahk"
    Use the real locations on your PC. This way it keeps working even if another program takes over opening .ahk files.

Don't tick "Run as administrator" on the shortcut (Shortcut tab, then Advanced). Caret Finder is designed to run as a normal user. If it's started as administrator, it will ask whether to close.

To stop it starting automatically, delete the shortcut from the Startup folder, or switch it off in Task Manager's Startup tab.

4. How to use it

  1. Click into a document, web page form, or anywhere you type, so the text cursor is there.
  2. Tap Shift twice quickly. Either Shift key works.
  3. A ring shrinks onto the text cursor and stays there.
  4. Press any key to make the ring fade away. You can simply carry on typing.

What counts as a double-tap

  • Two quick taps, no more than 0.4 seconds apart (adjustable: DoubleTapTime).
  • Each tap must be short; holding Shift down doesn't count (MaxTapHold).
  • Pressing any other key or clicking the mouse between the taps cancels it. Typing capital letters will never set it off by accident.

If you hear a sound instead

The Windows "Exclamation" sound means no text cursor could be found. For example, all windows are minimised, or you're on the desktop or in a program that doesn't report its cursor. See Troubleshooting.

5. How to configure it

Changing a setting

  1. Right-click the green H tray icon and choose Edit Script. Or open CaretFinder.ahk in Notepad.
  2. Find the block marked SETTINGS near the top. Each line looks like this: 
    RingRadius        := 45         ; Final radius of the ring around the cursor, pixels.
    Change only the value after :=. Text after a semicolon (;) is a comment and is ignored.
  3. Save the file.
  4. Right-click the tray icon and choose Reload Script.
  5. Use Test ring at mouse pointer from the tray menu to see the result.

Rules for values: colours and file names go in double quotes, e.g. "FFFF00"; numbers don't. Comment lines must start with a semicolon ;. A colon or anything else stops the script loading.

If a value is missing, not a number, or out of range, Caret Finder uses a safe default instead. A message lists what it replaced; it closes itself after a minute.

6. System tray options

Right-click the green H icon in the system tray (bottom right, by the clock) to open the menu. Hovering over the icon shows "Caret Finder - double-tap Shift to find the text cursor".

Caret Finder's own options (at the bottom of the menu)

Test ring at mouse pointer
Shows the ring around the mouse pointer. Use it to check the ring is working and to try out appearance settings. Press any key to dismiss it.
Show which method found the cursor
Ticks on or off. When ticked, a small note appears below the ring after each double-tap, saying how the cursor was found, e.g. "Caret found via: IAccessible2". It lasts until the script is reloaded. To keep it on permanently, set ShowMethodTooltip := true in the settings.

Standard AutoHotkey options (at the top of the menu)

Edit ScriptOpens CaretFinder.ahk in your text editor, so you can change the settings.
Suspend HotkeysHas no useful effect on Caret Finder. The Shift double-tap keeps working.
Pause ScriptNot recommended. The ring may appear late, after you unpause, or stay frozen on screen. Use Exit instead.
ExitCloses Caret Finder. Use this to turn it off. Start it again by double-clicking CaretFinder.ahk.

7. Troubleshooting

Nothing happens when I double-click CaretFinder.ahk

That's normal: there's no window. Look for the green H in the system tray, including behind the ^ arrow by the clock. If an error message appears instead, check the last line you edited. Comments must start with ;, and text values need double quotes.

I don't hear anything when no cursor is found

Check your volume. Right-click the speaker icon by the clock, choose Open Volume mixer, and make sure System Sounds isn't muted. You can also pick a different sound with NotFoundSound.

The ring appears in the wrong place in one program

Add that program's file name to SkipStandardMethodFor, e.g. ["soffice.bin"], save, then choose Reload Script. Switching on Show which method found the cursor helps show what's happening.

Firefox: it plays the "not found" sound

In Firefox, open Settings, then Privacy & Security, then Permissions. Make sure Prevent accessibility services from accessing your browser is not ticked. The first double-tap after Firefox starts can occasionally fail while Firefox switches its accessibility support on; just try again.

LibreOffice: it plays the "not found" sound

Go to Tools, then Options, then LibreOffice, then Accessibility. If your version has Support assistive technology tools, tick it and restart LibreOffice.

It can't find the cursor in a program running "as administrator"

Windows stops normal programs from reading windows that run as administrator. This is a safety feature, so leave it in place. Ordinary documents, browsers and editors aren't affected. Don't run Caret Finder as administrator to get around it.

A message says some settings weren't valid

The message lists each setting it replaced and the safe value it's using instead. Correct those lines in the settings, save, and choose Reload Script.

8. Privacy and security

  • Caret Finder only reads where the text cursor is. It doesn't record, store or send what you type.
  • It watches the keyboard only to notice the Shift double-tap and the key press that dismisses the ring. It doesn't collect text.
  • It makes no network connections and writes no files.
  • It needs no administrator rights, to install or to run, and never asks for them.
