Highlight Finder Alpha

Double-tap the right Shift key to circle the current search match, so you can see where Find has taken you.

By Ben Horton · 18 November 2026

This is alpha software. Highlight Finder is an early version that is still being developed and tested. It may not find the search match in every program or on every web page. It has been tested in Firefox, Chrome, Edge, LibreOffice Writer and WordPad. Settings and behaviour are likely to change between versions.

1. What it does

When you search a web page or document with Find (Ctrl+F), it can be hard to spot which highlighted word Find has moved to, especially when every match is highlighted. When you double-tap the right Shift key, Highlight Finder draws a bright yellow ring around the current match: the one Find has moved to, not the other highlighted matches.

  • The ring starts large and shrinks onto the match. Movement is easier to catch with side vision.
  • The ring is always the same size, centred on the middle of the match, however long the matched text is.
  • It stays on screen until you press any key, then fades away. That key still works normally, so you can press Enter in the Find bar to go to the next match.
  • If no current match can be found, you hear the Windows "Exclamation" sound.
  • The ring never takes focus and never blocks typing or clicking.

When the match is off-screen (Firefox)

Sometimes Firefox's current match isn't visible: you've scrolled away from it, or the page has hidden that text. In Firefox, Highlight Finder can still tell where it is. It shows half a ring on the edge of the page nearest the match, and a large yellow box with black text, such as:

The current match is off-screen above, or hidden by the page. Press Enter in the Find bar to go to the next match.

Like the ring, the box stays until you press a key.

Highlight Finder has been tested with Firefox, Chrome, Edge, LibreOffice Writer and WordPad. It's also designed to work with other browsers based on Chrome (Brave, Vivaldi, Opera), Microsoft Word and Notepad, but these haven't been tested yet.

Works alongside Caret Finder. Highlight Finder uses the right Shift key. Its companion, Caret Finder, uses the left Shift key to circle the text cursor. You can run either or both.

2. How to download

Highlight Finder is a single file called HighlightFinder.ahk. Get it from the project page on GitHub:

https://github.com/bthorton/cursor_finder

Option A: download everything as a ZIP (easiest)

  1. Open the project page linked above.
  2. Click the green Code button, then Download ZIP.
  3. Open your Downloads folder, right-click the ZIP file, and choose Extract All….
  4. Move the extracted folder somewhere permanent, for example your Documents folder. Don't leave it in Downloads if you plan to start it automatically.

Option B: download just the script

  1. On the project page, click HighlightFinder.ahk.
  2. Click the Download raw file button (a downward arrow, near the top right of the file).
  3. Move the file to a permanent folder, for example Documents.
  4. Optional: do the same for HighlightFinder.ico and put it in the same folder. It gives the tray icon its yellow "HF" look.

If Windows marks the file as downloaded from the internet: right-click HighlightFinder.ahk, choose Properties, and if there's an Unblock tick box at the bottom, tick it and click OK.

3. How to install (and what you need first)

What you need

  • Windows 10 or Windows 11.
  • AutoHotkey version 2. This free program runs .ahk scripts. Version 1 won't work; the script will tell you if the wrong version tries to run it.
  • Sound turned on, if you want to hear when no match can be found.
  • No administrator rights. Neither AutoHotkey (installed the ways below) nor Highlight Finder needs them.

Step 1: install AutoHotkey v2

If you already use Caret Finder, AutoHotkey is installed: skip to Step 2. Otherwise, choose one of these:

From the AutoHotkey website (recommended)
  1. Go to https://www.autohotkey.com and click Download, then choose v2.0.
  2. Run the installer. If it offers a choice, install for the Current user only, which doesn't need administrator rights.
With winget (Windows' built-in package manager)

Open a terminal (press Windows, type Terminal, press Enter) and run:

winget install --id AutoHotkey.AutoHotkey --exact

This downloads the official installer from the AutoHotkey Foundation.

Without installing anything (portable ZIP)
  1. On the AutoHotkey website, download the .zip version of v2 instead of the installer.
  2. Extract it into a folder of your own.
  3. To run Highlight Finder, right-click HighlightFinder.ahk, choose Open with, then Choose another app, and pick AutoHotkey64.exe from that folder.

AutoHotkey isn't officially available in the Microsoft Store. Avoid look-alike apps there.

Step 2: start Highlight Finder

  1. Double-click HighlightFinder.ahk.
  2. No window opens. That's normal. A small bright yellow square with black HF on it appears in the system tray, at the bottom right of the screen by the clock. If you can't see it, click the small up-arrow (^) next to the clock.
    The icon comes from HighlightFinder.ico, which must be in the same folder as HighlightFinder.ahk. Without it, you'll see AutoHotkey's standard green H instead; Highlight Finder still works.

Step 3 (optional): start it automatically when you sign in

  1. Right-click HighlightFinder.ahk and choose Create shortcut.
  2. Press Windows+R, type shell:startup and press Enter. Your personal Startup folder opens.
  3. Move the new shortcut into that folder.
  4. Recommended: right-click the shortcut, choose Properties, and set Target to name AutoHotkey itself, followed by the script in quotes. For example: 
    "C:\Program Files\AutoHotkey\v2\AutoHotkey64.exe" "C:\Users\YourName\Documents\Cursor_Finder\HighlightFinder.ahk"
    Use the real locations on your PC. This way it keeps working even if another program takes over opening .ahk files.

Don't tick "Run as administrator" on the shortcut (Shortcut tab, then Advanced). Highlight Finder is designed to run as a normal user. If it's started as administrator, it will ask whether to close.

To stop it starting automatically, delete the shortcut from the Startup folder, or switch it off in Task Manager's Startup tab.

4. How to use it

  1. Search with Find, usually Ctrl+F. In LibreOffice you can also use Find & Replace (Ctrl+H).
  2. Tap the right Shift key twice quickly. You can do this while you're still typing in the Find box.
  3. A yellow ring shrinks onto the current match and stays there.
  4. Press any key to make the ring fade away. Pressing Enter in the Find bar moves to the next match; double-tap right Shift again to circle that one.

What counts as a double-tap

  • Two quick taps of the right Shift key, no more than 0.4 seconds apart (adjustable: DoubleTapTime).
  • Each tap must be short; holding Shift down doesn't count (MaxTapHold).
  • Pressing any other key (including the left Shift key) or clicking the mouse between the taps cancels it. Typing capital letters will never set it off by accident.
  • Taps don't count while Ctrl, Alt or Windows is held down, so shortcuts such as Ctrl+Shift won't set it off.

How it finds the current match

Programs mark the current match in different ways, so Highlight Finder tries several methods, in an order that suits each program:

  • Firefox: asks Firefox where the current match is on the page. This also works when the match is off-screen.
  • Chrome, Edge and other browsers: looks on screen for the colour the browser paints the current match: orange in Chrome and Edge, green in Firefox. The other matches are painted yellow or pink, so they're ignored.
  • LibreOffice, WordPad, Word and others: Find selects the match, so Highlight Finder asks the program where the selected text is.

If you search using a separate Find dialog, such as LibreOffice's Find & Replace, Highlight Finder also looks in the document window behind it.

If you hear a sound instead

The Windows "Exclamation" sound means no current match could be found. For example, the search found nothing, the match has scrolled out of view (outside Firefox), or the program doesn't report its matches. See Troubleshooting.

5. How to configure it

Changing a setting

  1. Right-click the yellow HF tray icon and choose Edit Script. Or open HighlightFinder.ahk in Notepad.
  2. Find the block marked SETTINGS near the top. Each line looks like this: 
    RingRadius        := 45         ; Radius of the ring, in pixels.
    Change only the value after :=. Text after a semicolon (;) is a comment and is ignored.
  3. Save the file.
  4. Right-click the tray icon and choose Reload Script.
  5. Use Test ring at mouse pointer or Test off-screen warning from the tray menu to see the result.

Rules for values: colours and file names go in double quotes, e.g. "FFFF00"; numbers don't. Lists go in square brackets, e.g. ["FF9632", "38D878"]. Comment lines must start with a semicolon ;. A colon or anything else stops the script loading.

If a value is missing, not a number, or out of range, Highlight Finder uses a safe default instead. A message lists what it replaced; it closes itself after a minute.

6. System tray options

Right-click the yellow HF icon in the system tray (bottom right, by the clock) to open the menu. Hovering over the icon shows "HF".

Highlight Finder's own options (at the bottom of the menu)

Test ring at mouse pointer
Shows the ring around the mouse pointer. Use it to check the ring is working and to try out appearance settings. Press any key to dismiss it.
Test off-screen warning
Shows the half-ring and the large warning box, as if a match were off to the left of the window under the mouse pointer. Use it to check the warning is easy to read. Press any key to dismiss it.
Show colour under mouse pointer (copies it)
Counts down for 3 seconds while you point at the current match in your browser, then shows that colour's code, e.g. FF9632, and copies it to the clipboard. This replaces whatever was on the clipboard. Add the code to MatchColours if Highlight Finder doesn't find the match in your browser.
Show which method found the match
Ticks on or off. When ticked, a small note appears below the ring after each double-tap, saying how the match was found, e.g. "Match found via: Highlight colour". It lasts until the script is reloaded. To keep it on permanently, set ShowMethodTooltip := true in the settings.
Write a debug log
Ticks on or off. When ticked, Highlight Finder records each double-tap in the debug log (see DebugLog above). Useful when reporting a problem. It lasts until the script is reloaded.
Open the debug log
Opens the debug log in Notepad, if there is one.

7. Troubleshooting

Nothing happens when I double-click HighlightFinder.ahk

That's normal: there's no window. Look for the yellow HF icon (or a green H if HighlightFinder.ico is missing) in the system tray, including behind the ^ arrow by the clock. If an error message appears instead, check the last line you edited. Comments must start with ;, and text values need double quotes.

I don't hear anything when no match is found

Check your volume. Right-click the speaker icon by the clock, choose Open Volume mixer, and make sure System Sounds isn't muted. You can also pick a different sound with NotFoundSound.

In a browser, it plays the sound while the Find bar is open, or circles the wrong place

Your browser may paint the current match in a different colour; themes and dark mode can change it. Right-click the tray icon, choose Show colour under mouse pointer, and point at the current match within 3 seconds. Add the colour it shows to MatchColours, save, and choose Reload Script.

The search box appeared in an unusual place, and the ring doesn't find the match

Some websites replace the browser's own Find with a search box of their own, for example in the top right of the page. Those sites draw their own highlights, which Highlight Finder may not recognise. The browser's own Find bar appears at the bottom of the window in Firefox, and at the top right in Chrome and Edge.

Firefox shows only pink highlights, and Highlight Finder says the match is off-screen

With Highlight All switched on, Firefox shows the other matches in pink and only the current match in green. If you can't see any green, the current match is off-screen or in text the page hides (some shopping sites hide extra text for screen readers). Press Enter in the Find bar to go to the next match.

Firefox: it plays the "not found" sound

In Firefox, open Settings, then Privacy & Security, then Permissions. Make sure Prevent accessibility services from accessing your browser is not ticked. The first double-tap after Firefox starts can occasionally fail while Firefox switches its accessibility support on; just try again.

LibreOffice: it plays the "not found" sound

Go to Tools, then Options, then LibreOffice, then Accessibility. If your version has Support assistive technology tools, tick it and restart LibreOffice. Also note that LibreOffice only reports matches that are on screen: if you've scrolled away from the match, scroll back or search again.

LibreOffice: after "Find All", it circles only one match

Find All selects every match, so there's no single current match. Highlight Finder circles the first one it comes to. Use Find Next to step through matches one at a time.

It can't find matches in a program running "as administrator"

Windows stops normal programs from reading windows that run as administrator. This is a safety feature, so leave it in place. Ordinary documents, browsers and editors aren't affected. Don't run Highlight Finder as administrator to get around it.

A message says some settings weren't valid

The message lists each setting it replaced and the safe value it's using instead. Correct those lines in the settings, save, and choose Reload Script.

Reporting a problem

Right-click the tray icon and tick Write a debug log, repeat what went wrong, then choose Open the debug log. The log shows which methods were tried and what each found, which helps track the problem down.

8. Privacy and security

  • Highlight Finder reads where the current match is. To do that it may look at the screen, at your search word, and at the page text near the match. It uses these only in memory, for a moment, and never saves or sends them.
  • It watches the keyboard only to notice the right Shift double-tap and the key press that dismisses the ring. It doesn't collect what you type.
  • It makes no network connections.
  • It writes no files, unless you switch on the debug log. The log records right Shift presses, window titles and what each method found, never what you type, and stays in your own Temp folder.
  • It only writes to the clipboard when you choose Show colour under mouse pointer.
  • It needs no administrator rights, to install or to run, and never asks for them.
  • Keep the script in a folder only you can change. A script is a program: if someone else could edit it, their changes would run with your access the next time it starts. Your own Documents folder is safe by default.
